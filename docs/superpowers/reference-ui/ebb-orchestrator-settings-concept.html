Владение конфигурацией

Чёткая граница между версионируемой конфигурацией проекта и состоянием локальной машины.
Репозиторий (.orchestrator/) ├── project.yaml ├── workflows.yaml └── guidelines/ ├── architecture.md ├── database.md └── git.md Local SQLite / secure storage ├── absolute paths ├── Hermes sessions ├── task runtime state ├── approvals ├── usage ├── GitHub credentials ├── secrets └── recovery state
Конфигурация репозитория отвечает: «Как следует разрабатывать этот проект?»
Локальное состояние отвечает: «Что сейчас происходит на этой машине?»
Смысловые изменения утверждённых рекомендаций или процессов могут требовать согласования до активации.
