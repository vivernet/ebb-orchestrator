# Заметки пользователя к планированию

Этот реестр — место для записей пользователя, которые **не являются утверждённым планом**, но должны учитываться при разработке Ebb Orchestrator: необходимость выполнить план после определённых действий, промежуточные работы между планами, идеи на будущее.

## Статус документа

- **Неавторитетный источник:** записи сами по себе не разрешают реализацию. Право на реализацию даёт только утверждённый план.
- **Обязательность учёта:** перед составлением или существенным обновлением плана открытые записи должны быть сверены, а решение по каждой зафиксировано (учтено / отклонено / перенесено). Правило закреплено в `AGENTS.md`, §3, и в скилле `ebb-write-plan`.

## Правила внесения записей

1. Записи вносятся только с явного разрешения пользователя.
2. ИИ может предлагать добавить запись, но обязан сначала получить согласие.
3. Каждая запись кратко фиксирует суть, контекст/триггер и при необходимости ссылку на связанный план.

## Формат записи

```yaml
- id: IN-001
  date: 2026-10-22
  source: user | ai-suggestion
  status: open | considered | promoted | declined | done
  summary: <суть записи>
  context: <контекст, триггер, связь с планом>
  linked_plan: <PlanNN, если запись повышена до плана>
```

Статусы записей намеренно отличаются от статусов планов, чтобы реестр нельзя было спутать с утверждённым планом.
