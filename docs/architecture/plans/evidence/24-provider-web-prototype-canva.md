# Canva-прототип настроек ИИ-провайдеров (plan-24, Task 6)

Документ фиксирует визуальный референс экранов настройки ИИ-провайдеров Ebb Orchestrator, созданный в Canva (по решению пользователя «Для проработки веб-дизайна можешь использовать Canva»).

## Canva-дизайн

- Идентификатор дизайна: `DAHY38uN8Dg`
- Ссылка на просмотр/редактирование: https://canva.link/lm1p7cxiwa3dyf9
- Экспортированный референс (10 страниц, PDF): [24-provider-web-prototype-canva.pdf](24-provider-web-prototype-canva.pdf)

## Состав слайдов

1. Каталог провайдеров (поиск, фильтр категорий, сетка карточек, статусы).
2. Детали провайдера OpenAI (конфигурация, ключ API, проверка соединения, сохранить/отключить).
3. Форма ввода API-ключа без эха (placeholder; пояснение про `EBB_ORCHESTRATOR_HOME/.env`).
4. Поток OAuth / device-code (URL + код, ожидание, успех, истечение, отклонение).
5. Subscription-токен (поле токена, статус плана, обновить/отключить).
6. Cloud identity (предупреждение о необходимости настройки облачной идентичности).
7. Локальный endpoint (Base URL, предупреждение о локальной сети, проверка).
8. Модели и дефолты (поиск моделей, глобальная модель, модели по ролям).
9. Выбор модели для Run (форма запуска, отображение выбора на странице Run).
10. Состояния и ошибки (загрузка, пусто, ошибка, недоступно, отключено, истёк срок).

Дополнительно сохранён HTML-прототип с той же иерархией и состояниями: [24-provider-web-prototype.html](24-provider-web-prototype.html).

Дизайн не содержит реальных секретов, учётных данных или персонализированных значений.
