# Прототип переработки web UI и чата с координатором (plan-25, Task 0)

Документ фиксирует визуальный референс переработки веб-интерфейса Ebb Orchestrator по макетам `docs/architecture/reference-ui/*`, включая полноценный чат с координатором. HTML-прототип является обязательным и самодостаточным референсом.

## Референс прототипа

- HTML-прототип (самодостаточный, единый дизайн-система): [25-web-ui-prototype.html](25-web-ui-prototype.html)
- Дизайн-система (палитра из reference-ui):
  - Фон `#0b0d10`, панели `#12161b`/`#171c22`, границы `#252c34`
  - Акцент `#8ab4ff` · успех `#77d19a` · предупреждение `#e8c66a` · ошибка `#ef8e8e` · фиолетовый `#b79cff`
  - Сайдбар 230px, типографика Inter, тёмная тема.
- Экраны в прототипе: Dashboard (метрики, центр согласований, очередь, чат координатора), Проекты (index + страница проекта), Эпики (страница эпика), Задача (вкладки Обзор/Контракт/Запуски/Review/QA/Git/Использование), Центр согласований (approve/reject/request-changes), Очередь выполнения (capacity/locks/причины), Использование и бюджет, Настройки (роли/модели, scheduler, recovery, Git), Онбординг (5 шагов).
- Чат — компонент первого класса: история (роли user/coordinator/system), статусные сообщения, инлайн-одобрения `approval_request`, поле ввода, кнопки Одобрить/Отклонить/Запросить изменения.

## Canva-дизайн

Canva-дизайн прототипа чата с координатором создан (по решению пользователя «Для проработки веб-дизайна можешь использовать Canva»).

- Идентификатор дизайна: `DAHY4YjHF_k`
- Ссылка на просмотр/редактирование: https://canva.link/l6tjmcf23vndepf
- Экспортированный референс (PDF): [25-chat-prototype-canva.pdf](25-chat-prototype-canva.pdf)

Состав слайдов:

1. Dashboard с виджетом чата координатора (метрики, онбординг сообщений, инлайн-одобрения).
2. История сообщений: роли user/coordinator/system.
3. Статусная прогрессия планирования (RECEIVED → PLANNING → PLAN_PENDING_APPROVAL → MATERIALIZED) через SSE-события.
4. Инлайн-одобрение плана: Одобрить / Отклонить / Запросить изменения.
5. Поле ввода сообщения и состояние NEEDS_INPUT.

HTML-прототип является обязательным и самодостаточным референсом: [25-web-ui-prototype.html](25-web-ui-prototype.html).
